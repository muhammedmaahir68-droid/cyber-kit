* **Section 63 BNS 2023 & Section 65B BSA 2023 (Electronic Evidence Integrity)**:

## ⚖️ CHAPTER 3: JURY DEFENSE & TECHNICAL FAQS

### Q1: How does Case Copilot handle hallucinations?
Every factual response generated by Case Copilot is backed by explicit source citation chips (`[FIR-991/2025]`, `[CDR-T412]`). Spoken audio replies are strictly restricted to $\le 3$ sentences, ensuring concise, deterministic communication without conversational speculation.

### Q2: What if the local police station is offline with zero internet?
NCIS-TACTICAL is built with an offline-first architecture. The Hailo-8L NPU (26 TOPS) executes local vector embeddings, sector carving, and betweenness centrality calculation directly on the field unit without any cloud connection. When network connectivity is restored, telemetry synchronizes securely via encrypted mTLS.

### Q3: How does the system ensure data privacy under the DPDP Act 2023?
The facial recognition scanner converts detected faces into irreversible 128-dimensional floating-point vector arrays. No raw citizen images or unencrypted biometric files are stored in the database.
